# Estru-Tp
INSTRUCCIONES PARA EJECUTAR LOS PROGRAMAS

Abrir Visual Studio Code y abrir la carpeta principal del proyecto.

PYTHON

Se necesita tener Python instalado.

Entrar a la carpeta:

cd .\Gabriel_Gonzalez_Lujan_Rios_TP_Lenguajes\python\

Ejecutar:

python estudiantes.py

Si no funciona, probar:

py estudiantes.py


JAVA

Se necesita tener Java JDK instalado.

Entrar a la carpeta:

cd .\Gabriel_Gonzalez_Lujan_Rios_TP_Lenguajes\Java\

Compilar:

javac estudiantes.java

Ejecutar:

java estudiantes


C

Se necesita tener GCC o MinGW instalado.

Entrar a la carpeta:

cd .\Gabriel_Gonzalez_Lujan_Rios_TP_Lenguajes\C\

Compilar:

gcc estudiantes.c -o estudiantes.exe

Ejecutar:

.\estudiantes.exe


JAVASCRIPT

Se necesita tener Node.js instalado.

Entrar a la carpeta:

cd .\Gabriel_Gonzalez_Lujan_Rios_TP_Lenguajes\Javascript\

Ejecutar:

node estudiantes.js


RUBY

Se necesita tener Ruby instalado.

Entrar a la carpeta:

cd .\Gabriel_Gonzalez_Lujan_Rios_TP_Lenguajes\Ruby\

Ejecutar:

ruby estudiantes.rb


ACLARACION

Para salir de cada programa se debe seleccionar la opcion 9 del menu.
